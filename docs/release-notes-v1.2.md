# Work Usage Widget v1.2

First public version. [Download the APK](../downloads/ChatGPT_Work_Usage_v1_2.apk?raw=true).

- See your remaining five-hour and weekly allowance, reset times, and earned resets on your home screen.
- Enter values from the usage dashboard manually or try live sync through Codex device-code sign-in.
- v1.2 waits until you return to Work Usage before finishing device-code sign-in. Compatible phones use Android’s platform HTTP engine, and sign-in errors show which step failed.

**Android 8.0 or later.** See the [setup guide](guide.md) and [privacy notes](../PRIVACY.md).

Live sync was confirmed on an Android phone by the project owner. The [release checks](release-checks.md) record the checks completed for this version.
