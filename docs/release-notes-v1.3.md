# Work Usage Widget v1.3

[Download the APK](../downloads/ChatGPT_Work_Usage_v1_3.apk?raw=true) · [SHA-256](../downloads/SHA256SUMS) · Android 8.0+

- **Dark** keeps the original mint and blue palette. **Light** uses a pale background. **OLED** uses true black with lime and amber accents.
- **Widget style** previews each palette directly in the app using sample usage. Apply a style once to update all pinned Work Usage widgets without requesting a usage refresh.
- The widget’s refresh icon is announced as **Open Work Usage** when disconnected, matching what it does.

This APK uses the same package and signing certificate as v1.2. Open the APK and choose **Update** to keep your existing setup.
