# Work Usage Widget v1.4

[Download the APK](../downloads/ChatGPT_Work_Usage_v1_4.apk?raw=true) · [SHA-256](../downloads/SHA256SUMS) · Android 8.0+

- The new **Five-hour** and **Weekly** widgets each show one remaining allowance with a progress bar in a compact 2 × 1 layout. Pin either or both alongside the full dashboard.
- **Add to home screen** now lets you choose a layout. **Widget style** previews all three layouts in Dark, Light, or OLED.
- All widgets share the same saved usage and update together. Background refresh stays scheduled while any widget remains pinned and the app is connected.

Install over v1.3 to keep your sign-in, saved values, style, and pinned widgets. The APK uses the same package and signing certificate.
