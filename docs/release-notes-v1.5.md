# Work Usage Widget v1.5

[Download the APK](../downloads/ChatGPT_Work_Usage_v1_5.apk?raw=true) · [SHA-256](../downloads/SHA256SUMS) · Android 8.0+

- **Seven-day usage history.** Chart synced or manually entered allowances. Readings are saved on the phone starting with this version.
- **Low-usage alerts.** Opt in at 10%, 20%, or 30% remaining. Work Usage checks the thresholds after a successful sync.
- **Dashboard reset countdowns.** See the time until each known reset alongside its local time.
- **Ocean and Sunset themes.** Preview and apply them to the full, five-hour, and weekly widgets.

The v1.5 APK uses the same package and signing certificate as v1.4. Install it over your existing app to keep your saved values, sign-in, widget style, and pinned widgets.
