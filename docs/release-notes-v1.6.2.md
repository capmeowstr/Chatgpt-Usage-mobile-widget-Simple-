# Work Usage Widget v1.6.2

[Download the signed Android APK](../downloads/ChatGPT_Work_Usage_v1_6_2.apk?raw=true) · [SHA-256](../downloads/SHA256SUMS) · Android 8.0+

- **Disconnect** hides saved readings and clears local credentials and data independently of the network queue. Old refresh responses cannot repopulate cleared data.
- When a session ends, previously synced values and history are cleared. While signed out, **Clear saved usage** removes any remaining readings and history.
- New live-sync connections show a Codex permissions notice before requesting a device code. The one-time code is marked sensitive for accessibility on Android 14 and later.
- The optional local browser callback was removed. Device-code sign-in and manual entry remain available.

Install over v1.6.1 using the same Android package and signing certificate. [Privacy and account access](../PRIVACY.md) · [Previous release](release-notes-v1.6.1.md)
