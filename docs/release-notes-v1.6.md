# Work Usage Widget v1.6

[Download the APK](../downloads/ChatGPT_Work_Usage_v1_6.apk?raw=true) · [SHA-256](../downloads/SHA256SUMS) · Android 8.0+

- **Session planner.** Put both reported resets on one timeline, choose a 30- to 120-minute block, and see it starting now or at the next reported reset.
- **Allowance reserve.** Set 10%, 20%, or 30% to see each latest reported balance in relation to the reserve, in percentage points.
- **Next session widget.** Pin a 2 × 1 card that follows the lower reported percentage, highlights a reading below reserve, and opens the planner in one tap.
- **New GitHub previews.** The sample compares the same 60-minute work block at two start times.

The signed APK uses the same app ID and certificate as v1.5. Install it over v1.5 to keep your setup.
